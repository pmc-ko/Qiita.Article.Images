# Qiita.Article.Images

Qiita記事で使用する公開画像の保管・配信用リポジトリです。
記事本文と画像原本は記事管理側で編集し、投稿対象の記事が参照する画像をこちらへ配置します。

## 配置とURL

記事ごとの安定したslugで分けます。記事タイトルや公開日を変えても、画像用slugは維持します。

```text
images/
  article-slug/
    diagram-<sha256>.png
    screenshot-<sha256>.webp
```

配信URLの形式は次のとおりです。

```text
https://raw.githubusercontent.com/pmc-ko/Qiita.Article.Images/main/images/article-slug/diagram-<sha256>.png
```

ファイル名のSHA-256は画像の内容から求めます。画像を更新するときは、新しいハッシュのファイルを追加します。
既存ファイルは保持し、公開済み記事からの参照を維持します。

## 記事管理との連携

記事管理側の `images/<article-slug>/` に、公開する画像を明示して配置します。
投稿対象の選別と画像同期は、記事管理側のワークフローで行います。
下書き・将来の予約投稿・限定共有の記事は、公開画像同期の対象から外します。

画像は通常のGitファイルとして配信します。Git LFSのポインタではなく、画像本体を保持します。
新しい同期設定は記事管理側の手順・PRで確認してから有効化します。

## 権利と利用条件

画像の権利と再利用条件は、各画像および掲載記事の明記に従います。
リポジトリが公開されていることだけをもって、画像の再利用を許諾するものではありません。
